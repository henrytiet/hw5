# HW5 Part 4: Static Site Generator Exercise (Eleventy)

Two pages from my portfolio, **Home** and **Resume**, are generated by
[Eleventy](https://www.11ty.dev/) using Nunjucks templates. Both pages use one
shared layout and one shared footer.

## Files

| File | Purpose |
| --- | --- |
| `src/index.njk` | Home page content |
| `src/resume.njk` | Resume page content |
| `src/_includes/base.njk` | Layout both pages use: `<head>`, header and nav, `<main>` |
| `src/_includes/footer.njk` | **Shared footer**, included by the layout |
| `src/index.css`, `src/fact-panel.css`, `src/theme.js`, `src/js/`, `src/images/` | Styles, scripts, and images copied from the portfolio |
| `eleventy.config.js` | Eleventy settings: read from `src/`, write to `_site/`, copy assets |
| `package.json` | Dependencies and the `build` / `start` scripts |

## Commands

Run these from inside the `ssg-exercise/` folder (Node.js 18 or newer):

```sh
npm install      # install dependencies (Eleventy)
npm run build    # generate the site into _site/
npm start        # build, then preview at http://localhost:8080/ (rebuilds on save)
```

Pages to preview:

- Home: http://localhost:8080/
- Resume: http://localhost:8080/resume.html

## Checking the shared section

1. Change some text in `src/_includes/footer.njk`.
2. Run `npm run build` again (or save while `npm start` is running).
3. Refresh both pages. Both show the new footer.
